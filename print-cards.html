How to use these files
  1. QR images (ZIP): one file per card, named with its number and code (for example 017_KSAB12CD34). Give them to the card printer with the code list. Each card gets a different QR.
  2. PIN inserts: print this page on A4 at 100% and cut on the dashed lines. Each insert is card size and carries the PIN for one card.
  3. Packing: ask the printer to keep the cards in number order. Card 17 goes with insert 17. To check a card, scan it and look up its code in Card HQ: it shows the card’s number.
