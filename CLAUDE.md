# Rules for AI assistants working on this repository

This repository belongs to the GetKeepsake owner. These rules come from the owner and apply to every session.

1. **No change without the owner's permission.** Work only on a feature branch and open a pull request. Never push to `main`, merge, close pull requests, change settings, or deploy unless the owner explicitly says so in the current conversation (for example "merge").
2. **Show before merging.** Give the owner a preview link and wait for their go-ahead.
3. **Never put secrets in the code.** API keys, admin keys and payment keys live only in Vercel environment variables.
4. **Never edit a released asset file** (`assets/*.vN.js`). Make a new version (`vN+1`) and point the pages at it, because assets are cached for a year.
5. **Keep the code private.** Do not copy this code, its designs or its data into any other project, gist, paste site or public place.
